# Repository guidelines

- Write source identifiers, comments, docstrings, diagnostics, test names, UI
  text, and documentation in English.
- Keep setup and validation documents under `docs/`, using English filenames.
- Document project requirements rather than a particular developer's workstation.
- Keep local workspaces and operating-system metadata out of version control.
- Use Conventional Commits and the configured Git author identity.
- Do not add coauthor trailers. Do not push unless explicitly requested.
- Report build and test results accurately; prepared tests are not passing tests.
